# Screenshot inventory

This directory holds the UI captures referenced by the documentation. All
figures are wired in the pages already, and every referenced name currently
exists as a **navy placeholder labeled with its own filename** (so the site
builds warning-free) — replace a placeholder with the real capture of the
same name and rebuild.

Convention: 2× (HiDPI) capture, default dark theme, window ≥ 1600 px wide,
PNG. Gallery images are listed in `gallery.rst`; per-page figures use the
`<page>_<topic>.png` pattern and are declared next to a
`% TODO screenshot:` comment in their page.
